Es el mismo panel de la actividad n°2 pero conectado a la api de la materia, que usa express y mongodb, los estudiantes y los profesores se crean, se listan, se editan y se eliminan en la base de datos con fetch y async/await

Para correrlo primero se prende mongodb y la api de la materia (en su carpeta con npm start, queda en el puerto 9000) y después este proyecto con npm install y npm run dev, la dirección de la api está en el archivo .env.development
